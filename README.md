# ReLU-and-Tanh-Comparision-Experiments
Experiments on Non-Linear Activation Functions (ReLU and Tanh) in CNN, using CIFAR-10 data. A four-layer CNN with ReLU (blue line) reaches a 25% training error rate on CIFAR-10 six times faster than tanh (red line). ReLU with 5 epochs and Tanh with 29 epochs.
